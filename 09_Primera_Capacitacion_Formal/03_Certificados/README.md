# Certificados firmados

Los 12 PDF firmados están en esta carpeta. Selecciona el archivo por folio o nombre para abrirlo o descargarlo.

El QR impreso abre la consulta pública con el parámetro `folio`. El registro contiene los folios emitidos y las huellas SHA-256 de los PDF firmados. No muestra nombres ni otros datos personales.

Para cotejar tu PDF, abre [el buscador](https://soulkernel.github.io/GLF.P2/09_Primera_Capacitacion_Formal/03_Certificados/) e introduce el folio. Un archivo coincidente con el registro no sustituye la validación de la firma electrónica en FirmaEC.
